# PiratCrew ([link](https://piratcrew.netlify.app/))

## Jamstack architecture

- Nuxt - full static site generation
- Prismic as CMS
- Netlify AWS Lambda functions
- internationalization with Vue i18n ( En, Ru )
- Anime.js for animations
